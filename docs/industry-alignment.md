# Industry Alignment Report

The Industry Alignment Report provides a visualization of how an individual data set compares to industry averages (e.g., RESO-standardized fields or an IDX payload).

The goal of this report is to help data providers (e.g., MLS vendors) and their customers (e.g., MLSs) understand how their data compares to industry standards and identify opportunities for greater alignment.

The report includes three sections—[Insights](##insights), [Diagram](##diagram), and [Details](##details)—which can be accessed using the buttons at the top of the page.

# Insights

The Insights section shows how many of the top 100 Data Dictionary and IDX Payload data elements (fields and lookups) are included in the system and how many are missing. 

<img width="3033" height="1573" alt="image" src="https://github.com/user-attachments/assets/c17fec24-2766-4f61-a752-de48c9f97555" />

Select the numbers to see the specific data elements included in the count, along with additional details.

For example, selecting “7” in the example below reveals the fields included in that count, along with the number of _Unique Recipients_ and the _Availability Threshold_ in the [Details](##details) section.

<img width="776" height="300" alt="image" src="https://github.com/user-attachments/assets/e1cfbb61-4b07-45fb-bbfa-36c9577127cb" />

These fields may be considered for addition to improve industry alignment, or the organization may investigate why they are currently absent.

**Note:** The absence of a top 100 field doesn’t necessarily indicate a problem, as data needs can vary across markets.

## Filters

### Data Elements

Use the Data Elements buttons to filter by the following data sets:

- **RESO:** All resources, fields and lookups matching the RESO Data Dictionary standard
- **IDX:** Resources, fields and lookups for public display by an MLS broker participant
