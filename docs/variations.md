# Variations Report

The Variations Report is a visual representation of the data-dictionary-variations.json file, which is created during certification testing. 

The report highlights local data elements that are similar to those in the Data Dictionary and offers suggestions for standard elements for each one.

The suggestions include both automated machine suggestions as well as human suggestions from the RESO Fast Track Subgroup.

The following actions are available for each suggestion:

### Ignore
Ask to ignore the suggestion and keep the data elements as a local data element.

### Fast Track
Escalate the suggestion to the Fast Track Subgroup for discussion and reconsideration.

### Comment
Communicate with RESO staff about the suggestion.
